# 三、权限原则（按当前代码）

- `AGENT`
  - 创建/编辑草稿
  - 查看自己的申请列表和详情
  - 提交申请
  - 补件
  - 撤销申请
  - 候补确认
  - 接受/拒绝调剂
  - 上传文件

- `DOMESTIC_REVIEWER`
  - 国内审核认领
  - 国内审核提交
  - 查看申请详情
  - 可查看相关成绩单文件

- `SCHOOL_REVIEWER`
  - 学校审核 submit
  - 查看申请详情
  - 仅能处理自己 `school_code` 对应学校申请
  - 可查看相关成绩单文件

- `ADMIN`
  - 查看所有申请详情
  - 关闭申请
  - 管理批次、学校、专业、配额、用户、审计日志
  - 上传文件

注意：

1. 申请状态只能通过业务命令接口修改
2. 不允许直接改 `applications.current_status`
3. 首次登录且 `mustChangePassword=true` 时，仅允许访问 `/api/auth/me` 和 `/api/auth/change-password`

# 四、状态流转（按当前实现）

| 当前状态 | 业务动作 | 接口 | 下一个状态 |
| --- | --- | --- | --- |
| `DRAFT` | 提交申请 | `POST /api/applications/{id}/submit` | `SUBMITTED` |
| `DOMESTIC_SUPPLEMENT` | 重新提交 | `POST /api/applications/{id}/submit` | `SUBMITTED` |
| `SUBMITTED` | 国内审核认领 | `POST /api/domesticreviews/{id}/claim` | `DOMESTIC_REVIEWING` |
| `DOMESTIC_REVIEWING` | 国内审核通过 | `POST /api/domesticreviews/{id}/submit` | `SCHOOL_REVIEWING` |
| `DOMESTIC_REVIEWING` | 要求补件 | `POST /api/domesticreviews/{id}/submit` | `DOMESTIC_SUPPLEMENT` |
| `DOMESTIC_REVIEWING` | 国内拒绝 | `POST /api/domesticreviews/{id}/submit` | `DOMESTIC_REJECTED` |
| `DOMESTIC_SUPPLEMENT` | 补件上传 | `POST /api/applications/{id}/supplement` | 状态不变，仍为 `DOMESTIC_SUPPLEMENT` |
| `SCHOOL_REVIEWING` | 学校录取 | `POST /api/school-reviews/{id}/submit` | `RESERVED` |
| `SCHOOL_REVIEWING` | 学校候补 | `POST /api/school-reviews/{id}/submit` | `WAITLISTED` |
| `SCHOOL_REVIEWING` | 建议调剂 | `POST /api/school-reviews/{id}/submit` | 先 `ADJUSTMENT_SUGGESTED`，随后原申请 `CLOSED`，新申请 `DRAFT` |
| `SCHOOL_REVIEWING` | 学校拒绝 | `POST /api/school-reviews/{id}/submit` | `SCHOOL_REJECTED` |
| `WAITLIST_PENDING_CONFIRM` | 代理确认接受 | `POST /api/applications/{id}/waitlist-confirm` | `RESERVED` |
| `WAITLIST_PENDING_CONFIRM` | 代理拒绝 | `POST /api/applications/{id}/waitlist-confirm` | `CLOSED` |
| 调剂草稿 `DRAFT` | 接受调剂并提交 | `POST /api/applications/{id}/accept-adjustment` | `SUBMITTED` |
| `ADJUSTMENT_SUGGESTED` 或调剂草稿 `DRAFT` | 拒绝调剂 | `POST /api/applications/{id}/reject-adjustment` | `CLOSED` |
| `SUBMITTED / SCHOOL_REVIEWING / WAITLISTED` | 撤销 | `POST /api/applications/{id}/cancel` | `CANCELED` |
| `RESERVED / DOMESTIC_REJECTED / SCHOOL_REJECTED / CANCELED / WAITLIST_PENDING_CONFIRM / WAITLISTED / ADJUSTMENT_SUGGESTED` 等终结动作 | 管理员关闭 | `POST /api/applications/{id}/close` | `CLOSED` |

说明：

1. 当前代码里，补件接口只更新成绩单文件，不自动把状态改回 `SUBMITTED`
2. 真正回到 `SUBMITTED` 需要代理再调用一次 `/api/applications/{id}/submit`
3. `WAITLISTED -> WAITLIST_PENDING_CONFIRM` 当前通过 `POST /api/waitlists/{applicationId}/promote` 推进

# 五、认证模块

## 5.1 登录

**POST** `/api/auth/login`

请求：

```json
{
  "username": "agent01",
  "password": "agent123"
}
```

响应：

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "token": "jwt-token",
    "userId": 2,
    "username": "agent01",
    "role": "AGENT",
    "schoolCode": null,
    "mustChangePassword": true
  }
}
```

## 5.2 修改密码

**POST** `/api/auth/change-password`

请求：

```json
{
  "oldPassword": "agent123",
  "newPassword": "agent12345"
}
```

说明：

1. 首次登录返回 `mustChangePassword=true` 时，必须先调这个接口
2. 修改成功后会清空 `users.must_change_password`
3. 新密码长度至少 8 位，且不能与旧密码相同

## 5.3 当前用户

**GET** `/api/auth/me`

说明：

1. 登录成功会返回 `mustChangePassword`
2. 连续输错超过阈值会累计 `login_fail_count`
3. 超过阈值后会写入 `locked_until`

# 六、候补模块

## 6.1 查询候补详情

**GET** `/api/waitlists/{applicationId}`

## 6.2 推进候补

**POST** `/api/waitlists/{applicationId}/promote`

说明：

1. 仅 `SCHOOL_REVIEWER / ADMIN` 可调用
2. 推进后申请状态进入 `WAITLIST_PENDING_CONFIRM`
3. 系统会预占配额并写入 48 小时确认截止时间

## 6.3 失效候补

**POST** `/api/waitlists/{applicationId}/invalidate`

说明：

1. 仅 `SCHOOL_REVIEWER / ADMIN` 可调用
2. 如果候补已推进待确认，会同步释放预占配额
3. 超时扫描和批次结束扫描也会自动关闭候补

# 八、申请命令模块

## 8.1 提交申请

**POST** `/api/applications/{id}/submit`

说明：

- 支持 `DRAFT -> SUBMITTED`
- 支持 `DOMESTIC_SUPPLEMENT -> SUBMITTED`
- 会写规则快照、状态历史、审计日志

## 8.2 撤销申请

**POST** `/api/applications/{id}/cancel`

请求：

```json
{
  "reason": "学生主动放弃"
}
```

## 8.3 候补确认

**POST** `/api/applications/{id}/waitlist-confirm`

请求：

```json
{
  "accept": true
}
```

说明：

- 当前状态必须是 `WAITLIST_PENDING_CONFIRM`
- `accept = true` -> `RESERVED`
- `accept = false` -> `CLOSED`

## 8.4 接受调剂

**POST** `/api/applications/{id}/accept-adjustment`

请求：

```json
{
  "targetMajorCode": "USYD_BIZ"
}
```

说明：

- 当前调用对象是“调剂后生成的新草稿申请”
- 调用成功后会提交为 `SUBMITTED`

## 8.5 拒绝调剂

**POST** `/api/applications/{id}/reject-adjustment`

说明：

- 可用于拒绝 `ADJUSTMENT_SUGGESTED`
- 也可用于拒绝调剂草稿 `DRAFT`

## 8.6 关闭申请

**POST** `/api/applications/{id}/close`

权限：

- `ADMIN`

# 九、国内审核模块

## 9.1 认领申请

**POST** `/api/domesticreviews/{id}/claim`

说明：

- 当前状态必须为 `SUBMITTED`
- 状态变更为 `DOMESTIC_REVIEWING`

## 9.2 提交国内审核结果

**POST** `/api/domesticreviews/{id}/submit`

请求：

```json
{
  "materialComplete": true,
  "identityMatched": true,
  "basicScorePassed": true,
  "authenticityRiskLevel": "B",
  "standardizationPassed": true,
  "result": "PASS",
  "comment": "材料完整，成绩达标，可进入学校审核"
}
```

`result` 可选：

```text
PASS
SUPPLEMENT_REQUIRED
REJECT
```

状态变化：

- `PASS` -> `SCHOOL_REVIEWING`
- `SUPPLEMENT_REQUIRED` -> `DOMESTIC_SUPPLEMENT`
- `REJECT` -> `DOMESTIC_REJECTED`

说明：

- 当前仅实现了 `claim` 和 `submit`
- 暂未实现国内审核列表、详情、记录查询接口

# 十、学校审核模块

## 10.1 提交学校审核结果（唯一接口）

**POST** `/api/school-reviews/{id}/submit`

请求：

```json
{
  "school_threshold_passed": true,
  "major_threshold_passed": true,
  "school_quota_passed": true,
  "major_quota_passed": true,
  "academic_score": 62,
  "material_score": 16,
  "matching_score": 8,
  "total_score": 86,
  "review_result": "RESERVE",
  "review_reason": "达到占位线",
  "suggested_major_code": null
}
```

`review_result` 可选：

```text
RESERVE
SUGGEST_ADJUSTMENT
WAITLIST
REJECT
```

状态变化：

- `RESERVE` -> `RESERVED`
- `WAITLIST` -> `WAITLISTED`
- `REJECT` -> `SCHOOL_REJECTED`
- `SUGGEST_ADJUSTMENT` -> 原申请 `ADJUSTMENT_SUGGESTED -> CLOSED`，新申请 `DRAFT`

说明：

1. 当前学校审核只有这一个动作接口
2. 当前未实现学校审核列表、详情、记录查询接口
3. `SCHOOL_REVIEWER` 只能审自己学校申请
