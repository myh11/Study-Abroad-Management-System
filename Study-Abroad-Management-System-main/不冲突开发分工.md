# 🚫 三、强制规则（防冲突核心）

你直接复制发群👇

------

## ❗规则1：状态只能通过接口改

任何人不得直接：

+ 改数据库状态字段
+ 在前端写状态判断逻辑

👉 必须调用统一接口（你写）

------

## ❗规则2：公共文件只有你能改

包括：

+ application 表
+ 用户表
+ 状态枚举
+ 权限中间件
+ 路由主文件
+ API封装
+ 配额逻辑

------

## ❗规则3：一人一模块，不越界

+ A 不写审核
+ B 不写申请
+ 两人都不碰配额

------

## ❗规则4：接口先行

开发前你必须先给：

+ API接口格式
+ 请求参数
+ 返回结构

👉 他们只能调用，不能自己设计

------

## ❗规则5：一个 PR 只做一件事

例如：

✔ login页面
✔ 国内审核通过接口

❌ “登录+申请+审核一起改”
