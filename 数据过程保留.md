### 4. **审核数据（国内审核与学校审核）**

生成国内审核和学校审核的记录数据。

#### 给 Codex 的提示词

```text
你是一个资深 Java 后端工程师，请为“留学申请与审核系统”生成一份审核数据脚本，确保覆盖所有申请的审核过程。

【目标】
生成国内审核（`domestic_reviews` 表）和学校审核（`school_reviews` 表）的数据，确保数据完整：
1. 国内审核：
   - 至少为 `DOMESTIC_REVIEWING` 和 `DOMESTIC_SUPPLEMENT` 状态的申请生成审核记录

   - 包括 `review_result`（RESERVE, SUGGEST_ADJUSTMENT, WAITLIST, REJECT）和学业评分、匹配度评分等

【要求】
- 每条审核记录需关联对应的申请（`application_id`），并根据当前状态生成相应的审核内容
- 必须插入审核过程中的状态历史和审计日志
- 学校审核时要附带专业、学校评分等数据

【输出要求】
- 输出 SQL 脚本
- 确保能填充 `domestic_reviews` 和 `school_reviews` 表的数据
```
